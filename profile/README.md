# 🧰 Requirements

Before using ETS2Unlocker, make sure you have the following installed:

- A legitimate **Steam version** of **Euro Truck Simulator 2**
- The latest version of **CreamAPI**
- Active internet connection (required for SteamCMD fetching)
- **.NET 7 Runtime**

# 🔧 Troubleshooting

| Issue                 | Possible Fix                                          |
| --------------------- | ----------------------------------------------------- |
| DLCs missing in-game  | Restart Steam and rerun the activator as Administrator |
| Game fails to launch  | Verify ETS2 game files through Steam              |
| Activation process stuck  | Disable antivirus temporarily and retry               |
| DLC characters locked | Refresh Steam app cache and relaunch the game         |
| Errors after update   | Reapply the activator after game patches               |

# ❓ FAQ

## Does ETS2Unlocker work with cracked versions?
No. This tool is intended for official Steam copies of Euro Truck Simulator 2 only.

## Do I need to reinstall after every ETS2 update?
Usually yes. Major game updates may overwrite modified files.
